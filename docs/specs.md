# Specifications

pkpipe is built spec-first. The spec index with status and implementation order lives in the repository:
[specs/README.md](https://github.com/zskreisz01/pkpipe/blob/master/specs/README.md). Each spec folder holds
`spec.md`, `plan.md`, `tasks.md` and, where needed, `research.md` and `data-model.md`. The binding principles are in
[the constitution](https://github.com/zskreisz01/pkpipe/blob/master/.specify/memory/constitution.md).
